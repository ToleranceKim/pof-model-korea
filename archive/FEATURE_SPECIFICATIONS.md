# POF-Korea 변수 상세 명세서 (Feature Specifications)

> **⚠️ DEPRECATED**: 이 문서는 초기 계획 버전입니다. 최신 정보는 `/DATA_INTEGRATION_COMPLETE.md`를 참조하세요.
> - 실제 변수 수: 26-28개 (19개가 아님)
> - 실제 화재 비율: 육지 0.34%, 산림 0.21%

## 개요
본 문서는 한국 지역 화재 확률 예측 모델(POF-Korea)에서 사용되는 19개 입력 변수와 1개 라벨 변수의 상세 명세를 기술합니다.

## 변수 분류 체계
- **동적 변수 (Dynamic, 14개)**: 일별 또는 실시간 갱신
- **준정적 변수 (Semi-static, 3개)**: 월별 갱신
- **정적 변수 (Static, 5개)**: 고정값 또는 연별 갱신

---

## 1. 동적 변수 (Dynamic Variables)

### 1.1 기상 변수 (Weather Variables)

#### 1.1.1 t2m (2m Temperature)
- **설명**: 지상 2m 높이의 기온
- **자료형**: `float32`
- **단위**: Kelvin (K)
- **범위**: 일반적으로 240K ~ 320K (한국 지역)
- **소스**: ERA5 Reanalysis
- **갱신 주기**: 일별 (Daily)
- **결측치 처리**:
  - 시간 보간 (전후 3일 평균)
  - 공간 보간 (주변 격자 IDW)
- **특이사항**: UTC 00:00 기준 일 평균값

#### 1.1.2 td2m (2m Dewpoint Temperature)
- **설명**: 지상 2m 높이의 이슬점 온도
- **자료형**: `float32`
- **단위**: Kelvin (K)
- **범위**: 일반적으로 230K ~ 300K
- **소스**: ERA5 Reanalysis
- **갱신 주기**: 일별 (Daily)
- **결측치 처리**: t2m과 동일
- **특이사항**: 상대습도 계산의 기준 변수

#### 1.1.3 wind10m (10m Wind Speed)
- **설명**: 지상 10m 높이의 풍속
- **자료형**: `float32`
- **단위**: m/s
- **범위**: 0 ~ 30 m/s
- **소스**: ERA5 (10u, 10v 컴포넌트에서 계산)
- **계산식**: `wind10m = sqrt(10u² + 10v²)`
- **갱신 주기**: 일별 (Daily)
- **결측치 처리**: 컴포넌트 결측 시 0으로 처리
- **특이사항**: 화재 확산 속도 예측의 핵심 변수

#### 1.1.4 tp (Total Precipitation)
- **설명**: 24시간 누적 강수량
- **자료형**: `float32`
- **단위**: m (미터)
- **범위**: 0 ~ 0.5m (일반적으로 0 ~ 0.1m)
- **소스**: ERA5 Reanalysis
- **갱신 주기**: 일별 (Daily)
- **결측치 처리**: 0으로 대체 (무강수 가정)
- **특이사항**:
  - 음수값 발생 시 0으로 클리핑
  - 연료 습도에 직접적 영향

### 1.2 연료 습도 변수 (Fuel Moisture Variables)

#### 1.2.5 LFMC (Live Fuel Moisture Content)
- **설명**: 살아있는 식생의 수분 함량
- **자료형**: `float32`
- **단위**: % (백분율)
- **범위**: 50% ~ 200%
- **소스**: ECMWF 산출물
- **갱신 주기**: 월별 (2011-2021 실측, 이외 기간 climatology)
- **결측치 처리**:
  1. 실측값 우선
  2. Climatology (월별 평균)
  3. IDW 공간 보간 (반경 21 격자)
- **특이사항**: 산불 발생 임계값 약 80%

#### 1.2.6 LFMC_low (LFMC Lower Canopy)
- **설명**: 하층 캐노피의 연료 습도
- **자료형**: `float32`
- **단위**: %
- **범위**: 40% ~ 180%
- **소스**: ECMWF
- **처리 방법**: LFMC와 동일

#### 1.2.7 LFMC_high (LFMC Upper Canopy)
- **설명**: 상층 캐노피의 연료 습도
- **자료형**: `float32`
- **단위**: %
- **범위**: 60% ~ 220%
- **소스**: ECMWF
- **처리 방법**: LFMC와 동일

#### 1.2.8 DFMC_Foliage (Dead Fuel Moisture - Foliage)
- **설명**: 죽은 잎사귀의 수분 함량
- **자료형**: `float32`
- **단위**: %
- **범위**: 2% ~ 35%
- **소스**: ECMWF 산출물
- **갱신 주기**: 일별 (모델 계산)
- **결측치 처리**: LFMC와 동일한 3단계 처리

#### 1.2.9 DFMC_Wood (Dead Fuel Moisture - Wood)
- **설명**: 죽은 나무/가지의 수분 함량
- **자료형**: `float32`
- **단위**: %
- **범위**: 5% ~ 40%
- **소스**: ECMWF
- **처리 방법**: DFMC_Foliage와 동일

#### 1.2.10 fuelload_dead (Dead Fuel Load)
- **설명**: 죽은 연료의 적재량
- **자료형**: `float32`
- **단위**: kg/m²
- **범위**: 0 ~ 5 kg/m²
- **소스**: ECMWF/GFAS
- **갱신 주기**: 월별
- **결측치 처리**: 식생 타입별 기본값 적용

#### 1.2.11 fuelload_live (Live Fuel Load)
- **설명**: 살아있는 연료의 적재량
- **자료형**: `float32`
- **단위**: kg/m²
- **범위**: 0 ~ 10 kg/m²
- **소스**: ECMWF/GFAS
- **처리 방법**: fuelload_dead와 동일

### 1.3 기타 동적 변수

#### 1.2.12 lightning_flash_rate
- **설명**: 번개 발생률
- **자료형**: `float32`
- **단위**: flashes/km²/day
- **범위**: 0 ~ 10
- **소스**: Lightning Imaging Sensor (LIS)
- **갱신 주기**: 일별
- **결측치 처리**: 0 (무번개 가정)
- **특이사항**: 자연 발화의 주요 원인

#### 1.2.13 실시간 변수 1 (Reserved)
- **설명**: 향후 추가 예정
- **현재 상태**: 미구현

#### 1.2.14 실시간 변수 2 (Reserved)
- **설명**: 향후 추가 예정
- **현재 상태**: 미구현

## 2. 준정적 변수 (Semi-static Variables)

### 2.1 VOD-L (Vegetation Optical Depth - L band)
- **설명**: L-밴드 식생 광학 깊이
- **자료형**: `float32`
- **단위**: 무차원
- **범위**: 0 ~ 1.5
- **소스**: SMOS/SMAP 위성
- **갱신 주기**: 월별
- **결측치 처리**:
  - 월별 평균값 적용
  - 식생 타입별 기본값
- **특이사항**: 식생 수분 스트레스 지표

### 2.2 LAI_low (Leaf Area Index - Lower)
- **설명**: 하층 엽면적 지수
- **자료형**: `float32`
- **단위**: m²/m²
- **범위**: 0 ~ 8
- **소스**: MODIS MCD15A2H
- **갱신 주기**: 8일 → 월 평균
- **결측치 처리**:
  - 시계열 보간
  - 식생 타입별 기본값

### 2.3 LAI_high (Leaf Area Index - Upper)
- **설명**: 상층 엽면적 지수
- **자료형**: `float32`
- **단위**: m²/m²
- **범위**: 0 ~ 10
- **소스**: MODIS MCD15A2H
- **처리 방법**: LAI_low와 동일

## 3. 정적 변수 (Static Variables)

### 3.1 vegetation_type
- **설명**: 식생 유형 분류
- **자료형**: `int8`
- **범위**: 0 ~ 17 (IGBP 분류 체계)
- **소스**: MODIS MCD12Q1
- **갱신 주기**: 연별 (실제로는 거의 불변)
- **주요 코드**:
  - 1: Evergreen Needleleaf Forest
  - 2: Evergreen Broadleaf Forest
  - 3: Deciduous Needleleaf Forest
  - 4: Deciduous Broadleaf Forest
  - 5: Mixed Forest
- **특이사항**: 산림 필터링 기준 (코드 1-5)

### 3.2 orography
- **설명**: 지형 고도
- **자료형**: `float32`
- **단위**: m (미터)
- **범위**: 0 ~ 2000m (한국 지역)
- **소스**: SRTM DEM
- **갱신 주기**: 불변 (Static)
- **결측치 처리**: 해수면 기준 0m
- **특이사항**: 온도 보정 및 바람 패턴 영향

### 3.3 urban_fraction
- **설명**: 도시 지역 비율
- **자료형**: `float32`
- **단위**: 비율 (0-1)
- **범위**: 0.0 ~ 1.0
- **소스**: MODIS/Landsat 분류
- **갱신 주기**: 5년
- **결측치 처리**: 0 (비도시 가정)
- **특이사항**: 인위적 화재 위험 지표

### 3.4 population_density
- **설명**: 인구 밀도
- **자료형**: `float32`
- **단위**: 명/km²
- **범위**: 0 ~ 30,000 (서울 최대)
- **소스**: GPW v4 (2020년 기준)
- **갱신 주기**: 5년 단위
- **결측치 처리**:
  - 5년 구간 평균 (2000, 2005, 2010, 2015, 2020)
  - 2021년 이후는 2020년 값 사용
- **특이사항**: 인간 활동 화재 위험 대리 변수

### 3.5 road_density
- **설명**: 도로 밀도
- **자료형**: `float32`
- **단위**: km/km²
- **범위**: 0 ~ 50
- **소스**: OpenStreetMap
- **갱신 주기**: 연별
- **결측치 처리**: 0 (무도로 가정)
- **특이사항**: 접근성 및 인위 발화 위험

## 4. 라벨 변수 (Label Variable)

### af_flag (Active Fire Flag)
- **설명**: 화재 발생 여부
- **자료형**: `int8`
- **값**:
  - 0: 화재 미발생
  - 1: 화재 발생
- **소스**: MODIS/VIIRS Active Fire Products
- **탐지 기준**:
  - MODIS: MCD14ML (열적외선 이상 탐지)
  - VIIRS: VNP14IMG (375m 해상도)
  - Confidence ≥ 30% (nominal 이상)
- **시공간 집계**:
  - 공간: 0.1° 격자 내 1개 이상 탐지 → 1
  - 시간: 일 단위 집계 (UTC 00:00 - 23:59)
- **통계**:
  - 전체 positive 비율: 0.3955%
  - 산림 필터링 후: 0.8%
- **한계점**:
  - 구름 차폐 시 미탐지
  - 소규모 화재 (<1ha) 탐지 어려움
  - 2000년 11월 2일부터 데이터 존재 (MODIS 운영 시작)

## 6. 품질 관리 기준

### 6.1 유효 범위 검증
- 온도 변수: 물리적 한계 체크 (200K < T < 350K)
- 습도 변수: 0% ≤ 습도 ≤ 300%
- 풍속: 0 ≤ wind < 50 m/s
- 강수: 0 ≤ tp < 1m (일 강수)

### 6.2 시계열 연속성
- 급격한 변화 탐지 (3σ 규칙)
- 연속 결측 7일 이상 시 경고

### 6.3 공간 일관성
- 이웃 격자와의 차이 검증
- 고립된 이상치 제거

### 6.4 논리적 일관성
- td2m ≤ t2m (이슬점 ≤ 기온)
- LFMC > DFMC (일반적 경우)
- 산림 격자에서만 af_flag=1 허용
